## 后记

<div class="sub-h">Why This Blog</div>

lili 的 Blog 就这么开通了——2019 年，进京读研，总算有个地方可以好好写点东西。

作为程序员，blog 这种轮子要是挂在大众博客程序上就太没意思了。先后试过 CSDN、简书、开源中国，一是觉得太丑，二是不能随便定制——最后还是自己折腾了这个：自己写样式，自己排版。

鲁迅说：*写博客的最好时间是十年前，其次是现在。*

希望能在这里坚持写点东西，技术也好，生活也罢。借用 Steve Jobs 在斯坦福那场演讲：

> *"you can't connect the dots looking forward; you can only connect them looking backwards."*

## 之外 / Off the Page

<div class="sub-h">Beyond Code</div>

我喜欢做菜（最近在折腾川菜里的鱼香肉丝标准化）、跑步、看星星——后者大概是「outman」之外另一个我会反复回到的隐喻。还会拍点街头照，主要在北京西二旗到清河之间的几条街道。

顺便说一句，这个博客没有评论区，也没有阅读统计——不是清高，只是不想让数字成为写作的动机。技术栈很朴素：**Astro + Markdown + GitHub Pages**，自己排自己的版。
